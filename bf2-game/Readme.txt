Description
-----------

This file contains the installer for Battlefield 2 by Electronic Arts, "Complete
Collection" edition. As such it contains the base "vanilla" game, aleady patched
up to the latest version (patch 1.50, full build number: 1.5.3153-802.0), and the
expansion pack "Special Forces" as well as the additional booster packs "Armored
Fury" and "Euro Force" (which together consist of a total of six additional maps for
the base game, as well as new weapons and vehicles that are playable in those maps).

Additionally the installer contains the necessary DirectX 9.0c files and libraries that
are mandatory in order to play the game, and it is also bundled with the latest PunkBuster
definitions that were last released by EvenBalance for Battlefield 2. Server files are
included as well, in case you would like to host a Battlefield 2 server of your own.
NOTE: It is not necessary to run the server, in order to play the game online!

Lastly the installer can change the language of the game client (the default
language is English) and it also bundles a Key Manager software that allows you
to either input your own CD-Key for Battlefield 2 and Special Forces, or generate
a random new CD-Key (that you should write down).

Additional perks of this installer are the possibility to uninstall the game directly
from the Control Panel, custom HD launch shortcuts placed on the Desktop of the user,
and built-in fixes that can prevent some of the most common post-installation issues.


Requirements
------------

You need to have at least 4 GB of free space on your Computer.
The installer as well as the game are compatible with the following O.S.:
  • Windows XP
  • Windows Vista
  • Windows 7
  • Windows 8 and Windows 8.1
  • Windows 10


Installation
------------

Installing the game is very simple: first of all make sure to start by extracting the
contents of the .zip archive, secondly run setup.exe in order to start the installation.

Follow the instructions on the screen in order to proceed with the installation of the game.

At the end of the installation you will be prompted to install the DirectX 9.0c files and
libraries, and a tool by EvenBalance will be ran (in silent mode) in order to install the
PunkBuster services on your Windows machine.

Lastly you will be asked to input your CD-Key for Battlefield 2 and Special Forces. (If you
don't own or you've lost your CD-Key, click Random and then click Apply in the Key Manager).

In both scenarios please make sure to click Apply on the Key Manager, this is important.

After the installation is finished, an online image guide will be opened in your browser.
It will help you to download and install the BF2Hub Client as well as to create / retrieve
a Multiplayer account (always on BF2Hub). If you would like to configure the game to work
with a different online revival project / software, simply close the web page.


History of Battlefield 2
------------------------

Battlefield 2 (also known as BF2) is the third installment in the Battlefield
series and was developed by DICE. It was released on June 21, 2005 in North America.
The console port of the game, Battlefield 2: Modern Combat, was released on October
24, 2005. A sequel, Battlefield 3, was developed and released on October 25, 2011.

Official servers were shut down on June 30 2014, during the mass GameSpy server closure
by Glu Mobile that occured that day. The game can still be played online, through services
like BF2Hub, Gameranger and PlayBF2. The Revive BF2 Project (battlelog.co) used
to provide online services as well but was shut down by EA and DICE in October 2017.
